# DeepSeek Web Bridge

DeepSeek Web Bridge позволяет запускать Claude Code и OpenCode через вашу авторизованную веб-сессию DeepSeek. Bridge работает локально на компьютере и открывает Web UI по адресу `http://127.0.0.1:9655`.

Это не официальный API DeepSeek. Программа использует веб-сессию вашего аккаунта на `chat.deepseek.com`.

## Что нужно установить

- Node.js 20 или новее;
- Google Chrome;
- Claude Code или OpenCode;
- аккаунт DeepSeek;
- доступ к интернету.

## Как скачать

Откройте [GitHub Releases](https://github.com/serickprime/deepseek-web-bridge-public/releases/latest) и скачайте ZIP версии `v1.0.1`.

## Windows

1. Скачайте ZIP и полностью распакуйте его в обычную папку.
2. Дважды нажмите `START.bat`.
3. При первом запуске программа сама установит зависимости и соберёт Bridge.
4. Когда Bridge будет готов, автоматически откроется Web UI.
5. Нажмите **AUTH** и войдите в DeepSeek.
6. Выберите рабочую папку, Claude Code или OpenCode и нажмите запуск.

Не закрывайте окно `START.bat`, пока работаете с Bridge.

## macOS

1. Скачайте ZIP и полностью распакуйте его.
2. Дважды нажмите `START.command`.
3. Дождитесь, пока автоматически откроется Web UI.
4. Войдите в DeepSeek, выберите рабочую папку и Claude Code или OpenCode.

Если macOS блокирует файл, нажмите его правой кнопкой мыши и выберите **Открыть**. Либо откройте **Системные настройки → Конфиденциальность и безопасность** и разрешите запуск.

Только если двойной клик не работает, откройте Terminal в папке программы:

```bash
chmod +x START.command START.sh
./START.command
```

Не закрывайте окно `START.command`, пока работаете с Bridge.

## Linux

1. Скачайте ZIP и полностью распакуйте его.
2. Запустите `START.sh` двойным кликом или из терминала:

```bash
./START.sh
```

3. Дождитесь открытия Web UI.
4. Войдите в DeepSeek, выберите рабочую папку и Claude Code или OpenCode.

Если запуск файла запрещён:

```bash
chmod +x START.sh
./START.sh
```

Не закрывайте окно `START.sh`, пока работаете с Bridge.

## Как пользоваться

Главный сценарий одинаков на всех системах:

1. Скачайте ZIP.
2. Распакуйте архив.
3. Запустите START-файл для вашей системы.
4. Дождитесь открытия Web UI.
5. Войдите в DeepSeek.
6. Выберите рабочую папку.
7. Выберите Claude Code или OpenCode.
8. Запустите клиент.

Локальная авторизация хранится в папке `data/`. Не публикуйте и не передавайте эту папку другим людям.

## Возможные проблемы

- **Connection refused.** Bridge не запустился или порт 9655 уже занят.
- **Node.js не найден.** Установите Node.js 20 или новее и повторите запуск.
- **Ошибка 429.** DeepSeek временно ограничил запросы; подождите и повторите.
- **Истекла авторизация.** Снова нажмите **AUTH** и войдите в DeepSeek.
- **macOS блокирует запуск.** Разрешите файл в настройках безопасности macOS.
- **Ошибка после обновления Claude Code.** Новая версия клиента может изменить совместимость gateway; проверьте последнюю версию Bridge на странице Releases.

## Ручной запуск

Если START-файл не работает, откройте терминал в папке программы и выполните:

```bash
npm install
npm run build
npm start
```

Затем откройте `http://127.0.0.1:9655`.
