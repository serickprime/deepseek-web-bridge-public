# DeepSeek Web Bridge

DeepSeek Web Bridge позволяет запускать Claude Code и OpenCode через вашу
авторизованную веб-сессию DeepSeek. Bridge работает локально на вашем компьютере
и открывает локальный Web UI по адресу `http://127.0.0.1:9655`.

Это не официальный API DeepSeek. Проект использует веб-сессию вашего аккаунта
на `chat.deepseek.com`.

## Поддерживаемые системы

- Windows;
- macOS;
- Linux.

## Что нужно установить

- Node.js 20 или новее;
- Google Chrome для входа в DeepSeek;
- Claude Code или OpenCode;
- аккаунт DeepSeek;
- доступ к интернету.

## Как скачать

Рекомендуемый вариант — открыть страницу
[GitHub Releases](https://github.com/serickprime/deepseek-web-bridge-public/releases/latest)
и скачать архив версии `v1.0.0`.

Также можно скачать
[ZIP репозитория](https://github.com/serickprime/deepseek-web-bridge-public/archive/refs/heads/main.zip)
или выполнить:

```bash
git clone https://github.com/serickprime/deepseek-web-bridge-public.git
cd deepseek-web-bridge-public
```

## Установка и запуск на Windows

1. Скачайте и распакуйте архив.
2. Дважды нажмите `START.bat`.
3. При первом запуске программа сама установит зависимости и соберёт Bridge.
4. В браузере откроется Web UI.
5. Нажмите **AUTH**, войдите в DeepSeek и отправьте в открывшемся чате любое
   короткое сообщение, чтобы завершить авторизацию.
6. Выберите рабочую папку.
7. Выберите Claude Code или OpenCode и нажмите кнопку запуска.

## Установка и запуск на macOS

Распакуйте архив, откройте Terminal в папке программы и выполните:

```bash
chmod +x START.command START.sh
./START.command
```

При первом запуске будут установлены зависимости, собран Bridge и открыт Web UI.
Если macOS блокирует файл, откройте `START.command` через правую кнопку мыши →
**Открыть**. Затем нажмите **AUTH**, войдите в DeepSeek, выберите рабочую папку и
запустите Claude Code или OpenCode.

## Установка и запуск на Linux

Распакуйте архив, откройте терминал в папке программы и выполните:

```bash
chmod +x START.sh
./START.sh
```

Можно также разрешить запуск файла `DeepSeek Web Bridge.desktop` и открыть его.
После появления Web UI нажмите **AUTH**, войдите в DeepSeek, выберите рабочую
папку и запустите Claude Code или OpenCode. Для запуска из Web UI нужен один из
поддерживаемых терминалов: `x-terminal-emulator`, GNOME Terminal, Konsole,
XFCE Terminal, Kitty или Xterm.

## Ручной запуск

Если файл START не запускается, используйте терминал:

```bash
npm install
npm run build
npm start
```

После этого откройте `http://127.0.0.1:9655`. Для ручной авторизации доступна
команда `npm run auth`, для диагностики — `npm run doctor`.

## Как пользоваться

1. Запустите Bridge и не закрывайте его во время работы.
2. Авторизуйтесь в DeepSeek.
3. Выберите рабочую папку.
4. Выберите Claude Code или OpenCode.
5. Выберите модель `deepseek-v4-flash` и запустите клиент.
6. Работайте в открывшемся терминале как обычно.

Claude Code может показывать текст `API Usage Billing`, потому что подключён к
локальному Anthropic-compatible gateway. Само по себе это сообщение не означает
использование платного Anthropic API.

Сессия DeepSeek может истечь. В таком случае снова нажмите **AUTH** и войдите в
аккаунт. Локальные данные авторизации хранятся в папке `data/`; не публикуйте и
не передавайте эту папку другим людям.

## Возможные проблемы

- **DeepSeek вернул 429 / rate limit.** Подождите немного и повторите запрос.
- **DeepSeek временно недоступен.** Повторите попытку позже и проверьте сеть.
- **Сессия авторизации истекла.** Снова выполните вход через **AUTH**.
- **После обновления Claude Code появились ошибки.** Обновления клиента иногда
  меняют совместимость с локальными gateway; проверьте страницу Releases.
- **Порт 9655 занят.** Закройте другой процесс на этом порту или используйте уже
  запущенный Bridge.
- **Антивирус или ОС запрашивает разрешение.** Разрешите запуск локального Node.js,
  Chrome и терминала, если доверяете скачанному архиву.
- **VPN, proxy или сеть мешают подключению.** Временно проверьте работу без них;
  они могут влиять на соединение с DeepSeek.
