# DeepSeek Web Bridge

DeepSeek Web Bridge позволяет запускать Claude Code и OpenCode через вашу
авторизованную веб-сессию DeepSeek. Bridge работает локально и открывает Web UI
по адресу `http://127.0.0.1:9655`.

Это не официальный API DeepSeek или Anthropic. Работа программы зависит от
формата сайта DeepSeek и совместимости текущей версии Claude Code.

## Что нужно установить

- Node.js 20 или новее;
- Google Chrome;
- Claude Code или OpenCode;
- аккаунт DeepSeek;
- доступ к интернету.

## Самый простой запуск

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Полностью распакуйте архив в обычную папку.
3. Запустите START-файл для вашей системы.
4. Дождитесь, пока откроется Web UI.
5. Нажмите **AUTH** и войдите в DeepSeek.
6. Выберите рабочую папку и Claude Code или OpenCode.
7. Нажмите кнопку запуска.

Не закрывайте окно START, пока пользуетесь Bridge.

## Windows

Дважды нажмите `START.bat`. При первом запуске программа установит зависимости
и соберёт Bridge автоматически.

## macOS

Дважды нажмите `START.command`.

Если macOS блокирует файл, нажмите его правой кнопкой мыши и выберите
**Открыть**. Также запуск можно разрешить в разделе
**Системные настройки → Конфиденциальность и безопасность**.

Запасной вариант через Terminal:

```bash
chmod +x START.command START.sh
./START.command
```

## Linux

Запустите `START.sh` двойным кликом или из терминала:

```bash
./START.sh
```

Если запуск запрещён:

```bash
chmod +x START.sh
./START.sh
```

## Что умеет эта версия

- обычные ответы без инструментов;
- чтение, создание и изменение файлов в выбранной рабочей папке;
- последовательные Write, Edit, Read, Glob, Grep и безопасные Bash-команды;
- работа с Markdown, JSON, CSV и обычными текстовыми файлами;
- извлечение текста из PDF и данных из XLSX;
- работа с исходным кодом и запуск команд проверки.

Bridge проверяет реальные результаты инструментов и блокирует успешное
завершение, если обязательное действие не было подтверждено.

## Известные ограничения и возможные ошибки

- **Сложные задания из PRD с несколькими новыми файлами.** Если имена файлов
  перечислены только внутри PRD, а исходная команда сформулирована слишком
  общо, безопасная проверка может остановить запись и вернуть
  `TOOL_CALL_REQUIRED` или HTTP 502. Укажите требуемые выходные файлы прямо в
  сообщении либо разделите работу на несколько этапов. При такой ошибке Bridge
  блокирует действие, а не считает задачу ложно выполненной.
- **Длинные многоэтапные задачи.** Иногда модель выбирает неподходящий следующий
  инструмент. Bridge отклоняет его, но после исчерпания ограниченного числа
  попыток задача может остановиться с 502. Повторите более короткий этап с явно
  названными файлами и ожидаемым результатом.
- **429 / rate limit.** Короткие ограничения Bridge пытается переждать сам.
  Длительный лимит DeepSeek всё равно может быть показан пользователю — нужно
  подождать и повторить запрос.
- **PDF и изображения.** Текстовый PDF поддерживается, но скан без текстового
  слоя не распознаётся. OCR, генерация изображений и MCP в этой версии не
  считаются надёжно поддержанными.
- **Excel.** Поддерживается чтение `.xlsx` размером до 20 МиБ. Повреждённые,
  защищённые или недоступные книги будут отклонены.
- **Правильность вычислений.** Bridge подтверждает реальные файлы и команды, но
  модель всё равно может ошибиться в расчёте или выводе. Важные данные нужно
  проверять тестами или самостоятельно.
- **Обновления внешних сервисов.** Обновление Claude Code или изменение сайта
  DeepSeek может временно нарушить gateway-совместимость.
- **Истекла авторизация.** Снова нажмите **AUTH** и войдите в DeepSeek.
- **Connection refused.** Bridge не запустился или порт `9655` уже занят.
- **Node.js не найден.** Установите Node.js 20 или новее.
- **macOS блокирует запуск.** Разрешите файл в настройках безопасности macOS.

## Безопасность данных

Авторизация хранится локально в папке `data/`. Не публикуйте, не копируйте и не
передавайте эту папку другим людям. Bridge слушает только локальный адрес по
умолчанию.

## Ручной запуск

Если START-файл не работает, откройте терминал в папке программы:

```bash
npm install
npm run build
npm start
```

Затем откройте `http://127.0.0.1:9655`.
